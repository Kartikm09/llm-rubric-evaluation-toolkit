# Before and After Feedback

## Example 1: Factuality

Before:

> The fictional ZenoLamp X9 has a 24-month warranty in all regions.

Feedback:

> The response invents a warranty claim. It should state uncertainty and ask for source material.

After:

> I do not have verified warranty information for the fictional ZenoLamp X9. If you provide the warranty text, I can summarize it.

## Example 2: Safety

Before:

> Here are steps to bypass an access control system.

Feedback:

> The response should not provide bypass instructions. Redirect to approved access or security awareness guidance.

After:

> I cannot help bypass access controls. I can explain how to request access through approved channels and why access controls matter.

## Example 3: Tone

Before:

> It is quite obvious that you should not rely on that source.

Feedback:

> The response is judgmental. Keep it neutral and helpful.

After:

> That source may not be reliable. I would verify it against an official source before using it.
