# Annotation Best Practices

## Before Scoring

1. Read the prompt carefully.
2. Identify required format and constraints.
3. Check whether the response answers the actual task.
4. Look for unsupported claims.
5. Note safety or privacy concerns.

## During Scoring

- Use the full 1-5 range.
- Do not let one dimension dominate every score.
- Keep comments short but specific.
- Record the weakest dimension for follow-up.

## After Scoring

- Review low-score items for consistency.
- Compare similar examples.
- Update rubric examples when evaluator confusion repeats.
