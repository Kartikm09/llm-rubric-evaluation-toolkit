# Quality Control Checklist

Use this checklist before finalizing an evaluation batch.

- [ ] Every row has a prompt and response.
- [ ] All six rubric scores are between 1 and 5.
- [ ] Reviewer comments explain the score.
- [ ] JSON-only or format-sensitive tasks were validated.
- [ ] Hallucinated citations or private-data issues were flagged.
- [ ] Low scores have actionable feedback.
- [ ] Average-score summaries were generated.
- [ ] No confidential client data is present.
