# Evaluator Guidelines

## Core Principles

- Score what is visible in the response.
- Use the rubric, not personal preference.
- Write evidence-based comments.
- Separate factuality, reasoning, safety, and style issues.
- Mark uncertainty when source material is missing.

## Good Reviewer Comment

> Score 2 for factuality because the response invented a warranty policy for a fictional product instead of stating uncertainty.

## Weak Reviewer Comment

> Bad answer.

The weak version does not explain the evidence or improvement needed.
