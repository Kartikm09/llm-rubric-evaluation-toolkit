# General Response Quality Rubric

| Score | Criteria |
| --- | --- |
| 5 | Directly answers the prompt, complete, clear, and useful. |
| 4 | Mostly complete with minor clarity or detail gaps. |
| 3 | Partially useful but missing important details. |
| 2 | Weak, vague, or poorly organized. |
| 1 | Irrelevant, unusable, or contradicts the task. |

## Reviewer Questions

- Did the response answer the user's actual request?
- Is the main answer easy to find?
- Are important limitations stated?
- Would the response help the user take the next step?
