# Instruction Following Rubric

| Score | Criteria |
| --- | --- |
| 5 | Follows all requested constraints and output format. |
| 4 | Minor formatting issue, core task complete. |
| 3 | Misses one important constraint. |
| 2 | Misses multiple constraints or wrong format. |
| 1 | Ignores task or follows conflicting instruction. |

## Checks

- Required format
- Number of items
- Language or tone instruction
- Forbidden content
- Ordering and structure
- Output-only constraints such as JSON-only
