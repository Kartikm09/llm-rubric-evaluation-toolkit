# Contributing

Contributions should make the toolkit clearer, safer, and easier to use.

## Guidelines

- Use synthetic examples only.
- Keep rubrics evidence-based.
- Do not add private client data.
- Avoid harmful operational details.
- Keep scripts readable and standard-library only when possible.

## Good Additions

- New scored examples
- More evaluator guidelines
- Additional quality-control checks
- Cleaner feedback summaries
